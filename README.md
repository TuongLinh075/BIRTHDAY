# 🎁 Chiếc Hộp Quà Sinh Nhật Kỷ Niệm (Magic Birthday Box)

Trang web chúc mừng sinh nhật tương tác diệu kỳ - Mở hộp quà 3D, xem album ảnh kỷ niệm Polaroid, thổi nến sinh nhật và tích hợp sẵn Studio tạo thiệp tự động chia sẻ bằng một đường link duy nhất.

---

## ✨ Tính Năng Nổi Bật

1. **Trải Nghiệm Mở Quà 3D (The Unboxing Experience):**
   - Hộp quà 3D thắt nơ ruy băng đung đưa lấp lánh mang tên người nhận.
   - Chạm mở quà: Nắp hộp bật tung, pháo hoa giấy (confetti) nổ rực rỡ khắp màn hình.
   - Nhạc nền Kalimba (*Happy Birthday*) tự động ngân vang từ Web Audio API không phụ thuộc mạng.
   - Album ảnh kỷ niệm Polaroid bay lơ lửng ra ngoài, chạm vào để phóng to (Lightbox).
   - Chiếc bánh kem mini với ngọn nến lung linh: Chạm vào để thổi tắt nến, khói bay lên kèm lời chúc.
   - Bức thư chúc mừng với hiệu ứng chữ gõ máy tính (typewriter).

2. **Studio Tự Động Tạo Thiệp (Card Creator Studio):**
   - Điền tên người nhận, ngày sinh nhật, lời chúc (có sẵn các mẫu lời chúc gợi ý).
   - Tải lên từ 1 - 5 bức ảnh kỷ niệm (tự động nén chất lượng cao bằng Canvas).
   - 3 Phong cách màu sắc: *Sweet Pastel*, *Starry Gold*, *Warm Vintage*.
   - **Chia sẻ link bằng 1 chạm (Zero-Backend):** Dữ liệu được nén qua thuật toán `LZ-String` và gắn trực tiếp vào đường link URL. Không cần máy chủ backend, bảo mật tuyệt đối, gửi qua Zalo/Messenger/Facebook là mở xem được ngay.
   - Tích hợp sẵn Mã QR để quét mở trên điện thoại.

## 🚀 Hướng Dẫn Bật GitHub Pages (Miễn Phí)

Sau khi đưa code lên GitHub:
1. Vào mục **Settings** của repository trên GitHub.
2. Tại menu bên trái, chọn **Pages**.
3. Ở mục **Build and deployment** -> **Branch**:
   - Chọn nhánh: `main`
   - Chọn thư mục: `/ (root)`
   - Nhấn **Save**.
4. Sau 1 phút, trang web sẽ online tại địa chỉ:
   `https://TuongLinh075.github.io/BIRTHDAY/`
